# BiasLens roadmap

This roadmap describes planned work from the product's published boundaries.
It carries no delivery dates. A checked milestone means the capability is
implemented and verified, not merely proposed.

## Now

### Make investigations reviewable and reusable

Preserve the path from a question and source through claims, evidence and
uncertainty, while keeping model interpretation distinct from independent
verification.

- [ ] Let people save, revisit and revise investigations across sessions.
- [ ] Add independent source retrieval and traceable citations.
- [ ] Compare claims across sources without collapsing disagreement into a
  single truth or bias score.

### Make conversation analysis inspectable

Extend the transcript tools while retaining their current limits: overlap is
not proof of interruption, and a speaker label is not independently verified.

- [ ] Add reviewable source timestamps and correction history to conversation
  records.
- [ ] Evaluate audio and video transcription with editable speaker attribution
  before presenting derived comparisons.

## Later

### Support independent review

- [ ] Add moderated discussion and challenge resolution with a visible record
  of what changed and why.
- [ ] Evaluate reproducible production model and provider records without
  implying that provider availability establishes analysis quality.
